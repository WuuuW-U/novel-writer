# 墨笔 · 小说创作工具

一个轻量的小说写作辅助工具，纯前端，数据存储在浏览器 localStorage。

## 本地运行

```bash
python -m http.server 3001
# 或
npx serve .
```

然后访问 http://localhost:3001

## 技术栈

- 原生 HTML / CSS / JS
- 无后端依赖
- Google Fonts (Noto Serif SC, Noto Sans SC)

## 功能

- 富文本写作编辑器
- 章节管理（拖拽排序、字数目标、版本快照）
- 大纲树（卷→章→景三级）
- 角色卡 + 关系关联
- 时间线
- 世界观设定
- 写作统计 + 每日目标 + 7日趋势图
- 全文搜索
- 多种强调色主题
- 导出 TXT / HTML / JSON 备份
- 聚焦模式 / 阅读模式 / Markdown 预览

## 部署

推送到 GitHub 后，在 Vercel 导入仓库即可自动部署（无需配置）。
